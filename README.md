# Ternus Audiovisual Bayesian Causal-Inference Project

This repository contains data, analysis code, model implementations, and
figure-generation scripts for the audiovisual Ternus Bayesian
causal-inference study.

Authors: - Xiaoyi Jia - Lihan Chen

Affiliation: School of Psychological and Cognitive Sciences, Peking
University

Contact: xiaoyi_jia@stu.pku.edu.cn

## Overview

This project investigates audiovisual temporal organization using the
Ternus display paradigm and Bayesian causal-inference models.

The repository contains: - de-identified behavioral data -
psychophysical measurements - MATLAB analysis code - Bayesian
causal-inference models - model recovery and identifiability analyses -
figure-generation scripts

## Important notes

Baseline JND values are not assumed to be identical to latent sensory
noise. The baseline-informed model constrains relative auditory-visual
uncertainty while leaving absolute scale free.

Experimental stimulus presentation programs are not included.
