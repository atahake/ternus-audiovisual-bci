# Ternus Audiovisual BCI — Analysis Code

This folder contains MATLAB analysis code for the audiovisual Ternus Bayesian causal-inference study. It includes behavioral analyses, baseline psychophysics, model fitting, model recovery and identifiability diagnostics, baseline-informed model analyses, and figure-generation scripts.

## Software and dependencies

- MATLAB R2024 (the scripts may work in other recent releases, but the project was developed/tested for R2024).
- Statistics and Machine Learning Toolbox for functions including `glmfit`, `fitglme`, and `ttest`.
- Some group-level Bayesian model-selection options can use SPM12; the scripts report/handle its absence where supported.
- Several analyses are computationally intensive and can take substantial time. Run the stages in the order below and inspect the generated reports before starting later stages.

Do not place identifiable information in the public repository. The baseline psychophysics and audiovisual task files must preserve the variable structure expected by the analysis scripts.

## Analysis modules

- `01_MAIN_PIPELINE`: primary data audit, baseline psychophysics, behavioral summaries, timing-code audit, and initial analysis outputs.
- `02_BCI_CORE`: core audiovisual Bayesian causal-inference response and likelihood functions.
- `03_BEHAVIOR`: individual baseline psychometric curves, descriptive exports, and reliability/random-slope robustness checks.
- `04_FREE_BCI_RECOVERY`: primary R²-filtered model fitting, model comparison, model recovery, and parameter recovery.
- `05_IDENTIFIABILITY`: diagnostics for model confusion, prediction overlap, and parameter compensation.
- `06_BASELINE_INFORMED_BCI`: real-data comparison and recovery analyses for baseline-JND-informed relative sensory uncertainty.
- `07_RECOVERY_EXTENSIONS`: repeated recovery and trial-count sensitivity analyses.
- `08_FIGURES`: publication and supplementary figure generation.
- `09_TIMING`: code-level audit of the requested auditory/visual timing schedule. This does not substitute for hardware onset measurements.
- `10_SENSITIVITY`: AICc and model-selection sensitivity summaries.

## Recommended workflow

1. Put the de-identified input `.mat` files in `data/raw_deidentified/`.
2. Run `01_CODE/01_MAIN_PIPELINE/run_BCI_model_comparison_v4.m` for the initial audit and behavioral analysis. Inspect the generated QC and timing reports before proceeding.
3. Run `01_CODE/04_FREE_BCI_RECOVERY/run_BCI_R2filtered_recovery_v4.m` for the primary R²-filtered BCI analysis and model-recovery diagnostics.
4. Run `01_CODE/03_BEHAVIOR/run_reliability_random_slope_check.m` when its Phase-2 result file is available.
5. Run `01_CODE/06_BASELINE_INFORMED_BCI/run_JND_BCI_v1.m` for the baseline-informed model stages. This includes real-data fitting and synthetic recovery and can be computationally intensive.
6. Run the relevant export scripts in `03_BEHAVIOR` before `08_FIGURES/make_publication_results_figures_v8_figure2_revised_fix1.m`; that figure script expects the corresponding generated CSV/MAT outputs in `results/`.
7. Run `08_FIGURES/make_model_supplement_figures_v1.m` and `10_SENSITIVITY/summarize_AICc_sensitivity_v1.m` when their prerequisite model-fit outputs exist.

The scripts intentionally do not include the experimental stimulus-presentation program. The timing audit is a code-level schedule check only; it does not claim to reconstruct physical hardware onset times.

## Reproducibility notes

- Some scripts depend on intermediate outputs from earlier scripts. A missing-file error usually means that a prerequisite stage has not been run or its output has not been placed in `results/`.
- The final publication-figure script uses several CSV/MAT summaries generated by preceding analyses. Follow its missing-file messages rather than treating it as a standalone first step.
- Results from baseline-informed models are conditional on the assumed mapping from baseline auditory/visual JND ratios to latent sensory-noise ratios. JND is not assumed to equal latent sensory noise; the absolute scaling factor remains free.
- Model-recovery rates are conditional on the candidate model set, simulated parameter distributions, trial counts, fitting procedure, and model-selection criterion. They should not be interpreted as uniquely proving a cognitive mechanism.
- No claim is made here that the full pipeline has been executed from a clean checkout on an independent machine. It should be tested after the input data and required MATLAB toolboxes are available.

## Output location

Analysis products are written to subfolders under `results/`, including intermediate tables, model fits, recovery summaries, and figure exports. Do not commit large temporary workspaces, duplicate figure exports, or personally identifying raw data.
